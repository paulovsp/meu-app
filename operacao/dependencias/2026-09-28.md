Sem data exata dia-a-dia publicada pelo Expo, mas o app já está (ou está muito perto de estar) fora da janela de correções críticas.
- Fonte: [Expo SDK 54 — docs.expo.dev/versions/v54.0.0](https://docs.expo.dev/versions/v54.0.0/), [Expo changelog](https://expo.dev/changelog).

## Google Play

- Prazo de 31/08/2026 (já passado): apps novos e atualizações precisam mirar Android 16 (API 36); apps existentes precisam de pelo menos API 35 para continuar disponíveis a novos usuários em Android mais recente. Extensão disponível até 01/11/2026 para quem precisar de mais tempo — não é o caso do Dr.Sig.
- **O app já está em conformidade**: o `targetSdkVersion` padrão do Expo SDK 54 é **36**, acima do exigido. Sem override em `app.json` reduzindo isso. Nada a fazer aqui — o upgrade de SDK futuro mantém a conformidade.
- Fonte: [Target API level requirements — Play Console Help](https://support.google.com/googleplay/android-developer/answer/11926878).
