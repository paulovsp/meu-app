## Google Play

- Exigência vigente desde 31/08/2026: apps novos e atualizações precisam mirar Android 16 (API 36); apps existentes precisam de pelo menos API 35 para continuar disponíveis a novos usuários em Android mais recente. Extensão disponível até 01/11/2026 para quem pedir — não é o caso do Dr.Sig.
- **O app está em conformidade**: o `targetSdkVersion`/`compileSdkVersion` padrão do Expo SDK 54 é **36**, igual ao exigido. Sem override em `app.json` reduzindo isso. Nada a fazer aqui — o upgrade de SDK futuro mantém a conformidade.
- Fonte: [Target API level requirements — Play Console Help](https://support.google.com/googleplay/android-developer/answer/11926878).
